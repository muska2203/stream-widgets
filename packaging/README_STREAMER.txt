Interactive Story — интерактивная история для стрима
=====================================================

Чат Twitch голосует цифрами за варианты действий и коллективно проходит
текстовую историю. Картинка для зрителей — веб-оверлей, который
добавляется в OBS источником "Браузер".

УСТАНОВКА
---------
1. Распакуйте архив в любую папку (например, C:\InteractiveStory).
2. Запустите InteractiveStory.exe.
3. При первом запуске откроется мастер настройки:
   - Канал — ваш ник на Twitch (без #).
   - Токен — OAuth-токен с правом chat:read. Получить:
     https://twitchtokengenerator.com → Custom Scope Token → Chat: Read
     (кнопка-ссылка есть прямо в мастере).
   Настройки сохранятся в файлы config.toml и .env рядом с exe —
   больше мастер не появится. Чтобы изменить канал или токен позже,
   отредактируйте эти файлы или удалите их и запустите программу снова.

ПОДКЛЮЧЕНИЕ К OBS
-----------------
1. Запустите программу — в консоли появится адрес оверлея:
   http://127.0.0.1:8765
2. В OBS добавьте источник "Браузер" (Browser Source):
   - URL: http://127.0.0.1:8765
   - Ширина/высота: под вашу раскладку, например 900 x 1000.
3. Готово — фон прозрачный сам по себе, хромакей не нужен.
4. Тот же адрес можно открыть в обычном браузере для предпросмотра.
   Порт меняется в config.toml (overlay_port) — не забудьте обновить
   URL источника в OBS.

ИСТОРИИ И НАСТРОЙКИ
-------------------
- Истории — файлы в папке stories\ рядом с exe (формат TOML, внутри
  файлов есть примеры). Пул перечитывается при каждом новом выборе
  истории — редактировать можно без перезапуска программы.
- Тайминги (длительность голосования, паузы) и порт оверлея — в
  config.toml.
- mock_chat = true в config.toml — режим без Twitch (эмуляция чата),
  удобно для проверки.

ЗАМЕТКИ
-------
- Первый запуск может занять несколько секунд — это нормально.
- Если антивирус спрашивает про InteractiveStory.exe — это стандартная
  реакция на самораспаковывающиеся программы; файл безопасен
  (собран PyInstaller из открытого кода).
- Консольное окно программы показывает журнал и ошибки — не закрывайте
  его, оверлей живёт, пока жива консоль.
- Оверлей берёт шрифты с Google Fonts — нужен интернет (без него
  страница работает, но со стандартными шрифтами).
