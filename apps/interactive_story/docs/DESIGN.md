# Интерактивная история — DESIGN

Зрители чата Twitch коллективно проходят древовидную текстовую историю,
голосуя цифрами за варианты действий. Оверлей — локальная веб-страница
(`http://127.0.0.1:<overlay_port>`, адрес печатается при запуске), которую
стример добавляет в OBS источником «Браузер» (Browser Source);
прозрачность нативная, хромакей не нужен.

## Цикл игры

```
SELECT → VOTING → OUTCOME → SLEEP → VOTING → ... → END → SELECT → ...
```

- **SELECT** — экран выбора истории: список из пула, чат голосует цифрой
  (`select_duration` сек). Если история в пуле одна — выбирается сразу.
- **VOTING** — ход: сверху шапка «Название · Ход N · таймер», появляется
  текст сцены и сразу под ним варианты — голосование открыто с начала
  хода. Таймер хода единый: `round_duration` отсчитывается от показа
  сцены до конца голосования.
- **OUTCOME** — выбранный вариант подсвечен ярким зелёным, остальные
  остаются на экране; итог (`result` опции) пока не показывается. Пауза
  `outcome_pause` сек.
- **SLEEP** — сцена и варианты скрыты; остаётся шапка с названием истории,
  номером следующего хода и таймером до него, а наверху появляется текст
  итога выбора — он виден всё время сна. Пауза `sleep_duration` сек,
  затем следующий ход.
- **END** — концовка: заголовок `ending_label` + текст сцены, пауза
  `end_pause` сек, затем снова SELECT.

**Нет голосов — история не двигается**: раунд перезапускается на той же
сцене (и на выборе истории — тот же список). Переголосование разрешено,
при ничьей победитель случаен среди лидеров (правило streamkit).

## Команды чата

- `1`..`9` — номер варианта / номер истории на экране выбора.
- Всё остальное игнорируется.

## Пул историй

Одна история = один файл `apps/interactive_story/stories/<имя>.toml`.
Добавить историю = положить файл, удалить = убрать файл. Пул перечитывается
при каждом входе в SELECT — можно менять состав без рестарта игры.

### Формат файла

```toml
[meta]
title = "Название"          # обязательно
description = "Аннотация для экрана выбора"
start = "intro"             # id стартовой сцены, обязательно

[nodes.intro]
text = """Текст сцены (многострочный)."""
[[nodes.intro.options]]
text = "Вариант действия"   # обязательно
result = "Последствия"      # опционально; дефолт: "Чат сделал свой выбор."
next = "next_scene"         # обязательно, id существующей сцены

[nodes.next_scene]
text = "..."
ending = true               # сцена-концовка: без options
ending_label = "Хорошая концовка"  # опционально
```

Правила (проверяются при загрузке, битый файл роняет только выбор с
понятным сообщением; проверить пул: `py -m apps.interactive_story.core`):

- у не-концовки 1..9 опций (лимит цифр), у концовки опций нет;
- все `next` существуют; `meta.start` существует;
- из стартовой сцены достижима хотя бы одна концовка (циклы разрешены);
- неизвестные ключи игнорируются (запас под будущие поля, напр. голос TTS).

## Конфиг (`config.toml`)

`channel`, `select_duration`, `round_duration`,
`outcome_pause`, `sleep_duration`, `end_pause`, `seed`, `overlay_port`
(порт веб-оверлея), `mock_chat`.

## Запуск

```bash
py -m apps.interactive_story           # игра (mock_chat=false → живой Twitch)
py -m apps.interactive_story --smoke   # авто-выход через 20 с
py -m apps.interactive_story.core      # проверка пула историй
```

При старте печатается адрес оверлея (`http://127.0.0.1:8765`) — открыть в
браузере для предпросмотра или добавить в OBS источником «Браузер».
