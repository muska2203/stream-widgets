# Twitch Rubik's Cube — проектная документация

> Реализация и инженерные детали: [DEVELOPMENT.md](DEVELOPMENT.md).

Интерактивная мини-игра для стрима на Twitch: зрители чата коллективно собирают
кубик Рубика, голосуя текстовыми командами за каждый ход.

## 1. Игровой цикл

1. **Старт** — генерация перемешанного куба: 10 случайных ходов из того же
   набора команд, что доступен зрителям (гарантирует собираемость).
2. **Раунд голосования** — 15 секунд чат вводит команды, бот считает голоса.
3. **Применение хода** — команда-победитель выполняется с анимацией (~2–3 сек).
4. **Проверка победы** — куб собран → экран победы, пауза, рестарт с новой
   перемешкой. Иначе — следующий раунд.

## 2. Стек

| Компонент | Выбор | Назначение |
|---|---|---|
| Язык | Python 3.11+ | — |
| Рендер / окно | Ursina (Panda3D) | 3D-куб, анимации, безрамочное окно |

## 3. Архитектура

Переиспользуемая библиотека + игра поверх неё, слабо связанные:

- **`streamkit`** — библиотека стрим-интеграций (pip-пакет в этом репо,
  основа будущих мини-приложений; о кубе не знает):
  - `chat` — источники сообщений с единым интерфейсом (callback
    `on_message(user, text)` + `update(dt)` в игровом цикле): Twitch-чат
    (TwitchIO, чтение сообщений канала) и мок-чат для разработки без
    подключения;
  - `voting` — сбор голосов за раунд: один пользователь = один голос,
    переголосование разрешено (учитывается последняя команда), валидация
    через pluggable-валидатор, подсчёт, определение победителя (при
    равенстве — случайный лидер); `VoteLoop` — таймер раундов поверх;
  - `overlay` — boilerplate окна-оверлея для OBS (borderless, хромакей,
    always-on-top, drag/resize мышью, crisp-шейдеры);
  - `config` — загрузка TOML-конфига и `.env`.
- **`apps/rubiks_cube/core`** — чистая логика без графики: модель состояния
  куба (6 граней × 3×3), применение ходов, генератор перемешки, проверка
  «собран». Покрывается юнит-тестами (инверсия хода, идемпотентность
  4 поворотов и т.п.).
- **`apps/rubiks_cube`** (Ursina) — игра: окно, рендер куба, UI голосования,
  таймер, анимации, конечный автомат состояний:
  `VOTING → APPLYING → WIN/RESTART`.

Для разработки предусмотреть **режим эмуляции чата** (команды вводятся
локально/генерируются случайно) — работа без Twitch-подключения.

## 4. Команды чата

16 команд, регистронезависимые:

**Столбцы** (нумерация слева направо 1–3 относительно текущего вида):
- `u1` `u2` `u3` — столбец вверх
- `d1` `d2` `d3` — столбец вниз

**Строки** (нумерация сверху вниз 1–3):
- `r1` `r2` `r3` — строка вправо
- `l1` `l2` `l3` — строка влево

**Поворот всего куба** (whole cube):
- `wu` — весь куб вверх, `wd` — вниз, `wl` — влево, `wr` — вправо

Повороты всего куба нужны, потому что ходы строк/столбцов покрывают только
две оси вращения; чтобы крутить слои вокруг третьей оси, зритель сначала
разворачивает куб целиком. Перемешка генерируется из того же набора —
куб всегда собираем.

## 5. Голосование

- Длительность раунда: **15 сек** (конфигурируется).
- Один пользователь — один голос; повторная команда **заменяет** предыдущую
  (можно исправить опечатку).
- Невалидные сообщения игнорируются.
- Побеждает команда с наибольшим числом голосов; ничья — случайный лидер.
- На UI в реальном времени: счётчики голосов по командам и текущий лидер.

## 6. UI окна

- Безрамочное окно (borderless), фон — **хромакей `#FF00FF` (маджента)**
  (цвет в конфиге; не должен совпадать с цветами граней),
  захват в OBS + фильтр Chroma Key.
- На экране:
  - 3D-куб (во всю ширину окна);
  - верхняя полоса-таймер с секундами на ней;
  - таблица 16 команд: иконка хода, текст команды и счётчик голосов;
  - подсветка команды-лидера.
- Экран победы: «Куб собран!», пауза (в конфиге, по умолчанию 10 сек), рестарт.

## 7. Конфигурация (config.toml)

- `channel` — имя Twitch-канала;
- `round_duration` — 15;
- `animation_duration` — 2.5;
- `scramble_moves` — 10;
- `win_pause` — 10;
- `background_color` — `#FF00FF`;
- `window_size` — например 800×900;
- `always_on_top` — bool;
- `cube_tilt_x`, `cube_tilt_y` — наклон/поворот куба на экране (−30 / 35 по умолчанию);
- `mock_chat` — bool (режим эмуляции без Twitch).

OAuth-токен и ник бота — в `.env` (получение токена: twitchtokengenerator.com,
scope `chat:read`). Можно использовать отдельный бот-аккаунт или аккаунт
стримера — на работу не влияет.
